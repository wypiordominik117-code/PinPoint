# Pinpoint

1. Utwórz nowe repozytorium na github.com i wgraj tam wszystkie te pliki (razem z folderem .github).
2. Zakładka Actions -> "Build apps" -> Run workflow.
3. Po kilku minutach na stronie przebiegu pobierz z sekcji Artifacts:
   - Pinpoint-exe (Windows)
   - Pinpoint-apk (Android; przy instalacji zezwól na instalację z nieznanych źródeł)
4. Opcjonalnie: Settings -> Pages -> branch main, folder root. Strona dostanie adres https
   i da się ją zainstalować z przeglądarki (przycisk "Get app").

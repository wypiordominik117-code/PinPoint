Pinpoint

Open-source intelligence toolkit. Runs on your phone, nothing you type is uploaded.

Look up a target

Paste a domain, IP, URL, email, phone number or file hash. Pinpoint detects it and lists public sources to check.

Use public sources for security research, verification and journalism. Do not use them to track or harass private individuals, and follow the law and each site's terms.

Get the app

Install from the browser (works without a store):

  • iPhone: Safari, Share, Add to Home Screen.
  • Android: Chrome menu, Install app.
  • Windows or Mac: Chrome or Edge, install icon in the address bar.

Installing needs the page opened from its own https address, not from a downloaded file.
